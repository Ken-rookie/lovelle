Supabase connection

Use the same project as your Lovelle customer app.

Never use a service_role key in browser JavaScript. Client-side email checks are not a substitute for database Row Level Security (RLS).

Security checklist

Before using real customer data.

  • Use Supabase Auth for administrator sign-in.
  • Restrict products, orders, and customer records with server-enforced RLS policies.
  • Allow only approved admin accounts to update inventory and order status.
  • Do not expose PayMongo secret keys in this dashboard.
Apply the access-control migration in the customer app’s supabase/migrations folder. The browser email allowlist is not a substitute for its database role and RLS policies.
